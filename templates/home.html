Stock Report Generator

Enter a valid stock ticker symbol.
  • Generates analyst report from a ticker symbol.
  • The generation takes about 3-5min, download starts automatically or the error.
  • Best for dividend stocks as a DDM model is used.
  • Data sources: Alphavantage for fundamental, Yahoo Finance for Stock price and Finnbub for the News.
  • This is only a demo and the backend is API limited.
