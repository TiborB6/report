Stock Report Generator

The stock report generator creates an analyst report based on the ticker symbol provided.
The generation should take between 3-5 min. Once it is finished the download begins automatically, else you will get an error message.
It is best used for stocks with dividends as a DDM model is used to calculate the value of the company.
The fundamental and overview data is from alphavantage and the stock data is from yfinance.
The website is only for demo purposes, no uptime is guaranteed and the API calls on the backend are limited.
